# Password Checker

A Python tool that rates password strength and generates strong passwords.

## Features

- Estimates password strength in bits of entropy
- Detects very common passwords
- Gives tips to improve a weak password
- Generates secure random passwords

## Requirements

- Python 3.8 or newer
- No extra libraries needed

## Usage

```
python password_checker.py "MyPassword123"
python password_checker.py generate 16
```
